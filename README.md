A make.fun entry for [The Battery's Last Text to Its Charger](https://make.fun/bounty/u-alven-the-battery-s-last-text-to-its-charger-4278cfab).

`main.py` writes exactly one line — the phone battery's last text message
to the charger it waited for all day — to `/output/entry.txt`.

Run it:

```sh
python3 main.py
```
